# Meeting Planner

Современное веб-приложение для планирования встреч, с авторизацией, календарём и возможностью приглашать участников по email.  
Подходит для демонстрации навыков frontend + backend + базы данных на позиции junior web-разработчика.

![Скриншот интерфейса](./screenshot.png)

## 🚀 Функционал

- Регистрация и вход пользователя (JWT токены)
- Создание, редактирование и удаление встреч
- Просмотр встреч в календаре
- Отправка приглашений по email
- Адаптивный интерфейс (desktop и mobile)
- Тёмная и светлая темы

## 🛠 Технологии

**Frontend**:
- HTML, CSS, JavaScript (или Svelte/React/Vue)
- Fetch API / Axios
- FullCalendar.js (для календаря)

**Backend**:
- Python + FastAPI (или Node.js + Express)
- JWT авторизация
- SQLite / PostgreSQL

**Дополнительно**:
- Nodemailer / SMTP (отправка email)
- Render / Railway / Vercel (деплой)
